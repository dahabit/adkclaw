# المستوى الصفر — جولة في البنية المعمارية

![المستوى الصفر: جولة في البنية](img/architecture.png)

**اعرف الأرض قبل أن تبني عليها. تعلّم الستة أعمدة لأي وكيل ذكي ذاتي التصرّف، وتجوّل في مستودع AdkClaw من أعلاه إلى أسفله.**

أنت على وشك بناء وكيل ذكي ذاتي التصرّف عبر المستويات الأربعة القادمة. قبل أي سطر برمجي، تحتاج إلى خريطة للأرض: ما هو الوكيل فعلًا، ما الذي يجعله ذاتي التصرّف، ما الجزء الذي تقدّمه Google وما الذي يأتي من المصادر المفتوحة، وأين يعيش كل مفهوم في قاعدة الكود. القليل من التوجيه الآن يوفّر عليك ساعات من الحيرة لاحقًا.

## 🎯 ماذا ستتعلّم؟

| المفهوم | الوصف |
|---------|-------|
| **الستة أعمدة لأي وكيل ذاتي التصرّف** | العقل، الأدوات، الذاكرة، الشخصية، الشفاء الذاتي، الوكلاء الفرعيون — كل واحد يقابل ورشة |
| **أساسيات Google ADK** | حزمة `@google/genai`، نماذج Gemini، استدعاء الدوال، grounding |
| **منطق اختيار التقنيات** | لماذا TypeScript، لماذا SQLite، لماذا بدون LangChain — كل قرار يمكن الدفاع عنه |
| **هيكلة المستودع** | كل مجلّد يقابل عمودًا، وكل ورشة تقابل مجلّدًا |
| **إعداد بيئة Cloud Shell** | `./scripts/setup.sh`، متغيّرات البيئة، اختيار المشروع، تفعيل الـAPIs |
| **الرحلة كاملة** | ما الذي ستحصل عليه في نهاية كل مستوى |

## ✅ ماذا ستبني؟

في نهاية هذا المستوى، ستحصل على:

- 🧭 صورة ذهنيّة واضحة عن الوكيل الذاتي — ليس مجرد chatbot بإضافات
- 📂 نسخة من المستودع مثبّتة على Cloud Shell بكل اعتماديّاتها
- 🔑 الـAPIs المُفعّلة (Vertex AI, Cloud Run, Cloud Build, Secret Manager, Firestore, Cloud Storage, Cloud Scheduler)
- ✅ نتيجة خضراء كاملة من `npx adkclaw check`
- 🚀 الثقة لتبدأ البناء في المستوى الأول

هذا المستوى **عرضي بطبيعته** — لا يوجد كود وكيل بعد. تقرأ، تشاهد العرض الحيّ، تجهّز البيئة. عدد أسطر الكود اليوم: صفر. عدد المفاهيم المُغطّاة: ضخم.

## 📋 المتطلّبات

- ✅ مشروع Google Cloud مع تفعيل الفوترة
- ✅ Cloud Shell (المُوصى به) أو بيئة محلّية بـNode.js 22+
- ✅ مفتاح Gemini API مجّاني من [aistudio.google.com/apikey](https://aistudio.google.com/apikey) (يُستخدم في L1)
- ✅ توكِن بوت Telegram من [@BotFather](https://t.me/BotFather) (يُستخدم في L1) — أرسِل `/newbot`
- ✅ كتلة توجيه قصيرة + فحص بيئة

## 🚀 البداية السريعة

### 1. افتح Cloud Shell

اذهب إلى [console.cloud.google.com](https://console.cloud.google.com)، اختر مشروعك، واضغط على أيقونة الترمنال (أعلى اليمين) لفتح Cloud Shell.

### 2. انسخ المستودع

```bash
git clone https://github.com/dahabit/adkclaw.git
cd adkclaw
```

### 3. شغّل سكربت الإقلاع

```bash
./scripts/setup.sh
```

السكربت يقوم بـ:
- التحقّق من تسجيل الدخول إلى gcloud والمشروع النشط
- تفعيل الـAPIs المطلوبة (Vertex AI, Cloud Run, Cloud Build, Secret Manager, Storage, Cloud Scheduler, Logging)
- يطلب رمز الحدث واسم المستخدم (استخدم `sandbox` للتعلّم الذاتي)
- يطلب مفتاح Gemini وتوكِن Telegram (أو تخطّى — تستطيع إضافتهما في L1)
- يكتب `config.json` و `set_env.sh` لبقيّة الورشة

### 4. حمّل ملف البيئة

```bash
source ~/adkclaw/set_env.sh
```

### 5. اقرأ نظرة على البنية المعمارية

```bash
cd level_0
cat docs/teaching-guide.md
```

تصفّح أقسام **الستة أعمدة** و**لماذا TypeScript / لماذا Google ADK** و**مسار الطلب**.

### 6. تجوّل في المستودع (مع المُدرّس أو ذاتيًّا)

```bash
# المستوى الأعلى
ls

# اقرأ وثيقة هيكلة المستودعات الثلاثة
cat ARCHITECTURE.md

# نقطة البداية ليوم اليوم — ابنِ عليها
ls codelab/starter/

# المرجع الكامل بعد L4 (للدراسة، لا للنسخ)
ls src/

# تعليمات الكودلاب لكل مستوى (Markdown فقط)
ls level_0/ level_1/ level_2/ level_3/ level_4/ level_5/
```

### 7. شغّل الفحص التحضيري

```bash
cd level_1
npm install
npx adkclaw check
```

يجب أن ترى علامات خضراء كاملة. إذا كان `ALLOWED_SENDERS` ناقصًا، فهذا متوقَّع — المستوى الأول يغطّي إعداد Telegram.

## 🏆 اختياريّ: انضمّ إلى أسطول الكوهرت

وكيلك يستطيع تسجيل تقدّمه تلقائيًّا على **[adkclaw.dev](https://adkclaw.dev)** ليظهر على الأسطول الحيّ، ويربح الأربعة شارات (الخمسة بعد L5)، ويحصل على ملف عام في `adkclaw.dev/u/<your-username>`.

هذه الخطوة اختياريّة — الوكيل يعمل بكامل وظائفه بدونها.

### كيف تسجِّل

1. افتح **[adkclaw.dev/join/sandbox](https://adkclaw.dev/join/sandbox)** (أو رمز الحدث الخاص بمدرّبك إن أعطاكه).
2. اختر نفس `username` الذي وضعته في `./scripts/setup.sh`.
3. اختر صورتك الشخصيّة.
4. الصفحة تعرض **builder secret** الخاص بك مرّة واحدة فقط — انسخه الآن، فلن تراه ثانية.

### كيف تربط الأمر

أضِف الـsecret إلى `.env`:

```bash
# ألحقه بـ ~/adkclaw/set_env.sh
echo 'export ADKCLAW_BUILDER_SECRET="paste-the-secret-here"' >> ~/adkclaw/set_env.sh
source ~/adkclaw/set_env.sh
```

هذا كل شيء. عندما ينهي وكيلك مستوى، يستدعي `mark_level_complete` وتضيء الشارة على الأسطول خلال ثانيتين.

| المستوى | متى تضيء الشارة |
|---------|-----------------|
| 1 | عند انتهاء أوّل محادثة Telegram |
| 2 | عند حفظ أوّل حقيقة في الـbank وتشغيل compaction مرّة |
| 3 | عند إطلاق وكيل فرعي وعودة نتيجته |
| 4 | عند نشر الوكيل على Cloud Run بعنوان عام |
| 5 | عند نجاح فحص الأمان (`npm run audit:security`) |

## 🔑 الستة أعمدة (النموذج الذهني)

كل وكيل ذاتي التصرّف يحتوي على ستّة أشياء. أزل أيّ واحدة، يتوقّف عن كونه ذاتيًّا. AdkClaw يُدرِّس كلّ واحدة بأن تبنيها:

| العمود | المعنى | المكان | الورشة |
|--------|--------|--------|--------|
| **العقل (Brain)** | النموذج اللغوي الذي يُفكِّر (Gemini عبر ADK) | `src/agent/runner.ts` | المستوى 1 |
| **الأدوات (Tools)** | الأيدي للتصرّف في العالم | `src/tools/` (21 أداة) | المستوى 1 |
| **الذاكرة (Memory)** | تنجو من الجولات والأيام وإعادة التشغيل | `src/context/`, `src/memory/`, `workspace/` | المستوى 2 |
| **الشخصيّة (Personality)** | هويّة ونبرة، ليس مجرّد نص | `workspace/IDENTITY.md`, `SOUL.md` | المستوى 1 |
| **الشفاء الذاتي (Self-healing)** | لا يتعطّل أبدًا — يتعافى من أيّ خطأ | `src/healing/` | المستوى 3 |
| **الوكلاء الفرعيّون (Sub-agents)** | متخصّصون يتعاونون مع الوكيل الرئيسي | `src/multi-agent/` | المستوى 3 |

**chatbot** يملك العقل فقط. **RAG** يملك العقل + الاسترجاع. **الذاتيّة** تعني الستّة كلّها.

## 🏁 جاهز للمستوى الأول؟

قبل أن تتقدّم، تحقّق:

- [ ] `./scripts/preflight.sh` ينجح في الفحوصات السبعة كلّها
- [ ] تستطيع تسمية الستّة أعمدة من ذاكرتك
- [ ] في `.env` لديك `GEMINI_API_KEY` و `TELEGRAM_BOT_TOKEN` حقيقيّان (ليس placeholders)
- [ ] تعرف معرّفك الرقمي على Telegram وجاهز لـ `ALLOWED_SENDERS`
- [ ] نسخت المستودع و `cd codelab/starter && npm install` اكتمل

إذا أيّ شيء أحمر، راجِع [`PREWORK.md`](../PREWORK.md) — يوم البداية يجب أن يكون أخضر.
